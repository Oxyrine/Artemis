# Reconciliation workspace

Mode: Operate. Scope: dashboard, case review, audit ledger, shared shell.

## Direction contract

THESIS: Give a financial workspace the character and hierarchy of an annual report. The user rejected the preceding achromatic layout as bland and generic; this revision intentionally replaces that world.

OWN-WORLD: Deep ink navigation, cobalt actions, cool paper canvas, self-hosted Instrument Serif titles and Geist data. A navy reconciliation panel uses actual explained and held paise as a split bridge. White working surfaces, 12px corners, quiet table rules, readable semantic status labels. Data remains the material; no decorative stock imagery or invented performance figures.

STORY: Scan outcomes and amounts, search a receipt or customer, inspect a case's closure and evidence, then record a named decision. Verify the history separately.

FIRST VIEWPORT: A 246px dark navigation column with a receipt–evidence–decision chain; 48px serif page heading; compact agent toolbar; an asymmetric navy financial overview and white outcome index; then the receipt queue. Primary action: cobalt Run batch. Phone: stacked overview, compact outcomes, receipt cards. Case review and audit inherit the editorial headings and ink/cobalt system.

FORM: Editorial financial reporting. User-directed replacement of the previous dealt achromatic ledger; the original seed no longer governs visual choices. Impeccable engine unavailable; no comp reference. Product-specific signatures: a live variance bridge and the evidence-to-decision workflow. All global financial totals remain stable when the queue is filtered.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
